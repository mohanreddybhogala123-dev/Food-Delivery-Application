# 🍔 Food-Delivery-Application (Foodwala)

A robust web-based **Food Delivery Application** built using Java Servlets, JSP, and Apache Tomcat. This application allows users to browse food items, manage their cart, place orders, and track them seamlessly.

---

## 🚀 Features

* **User Authentication:** Secure user registration, login, and session management.
* **Menu Browsing:** Browse various food categories and food items with details.
* **Cart Management:** Add, update, or remove food items from the shopping cart.
* **Order Placement:** Seamless checkout and order placement system.
* **Order Tracking:** View past and current order statuses.

---

## 🛠️ Tech Stack

* **Backend:** Java, Servlets, JDBC
* **Frontend:** JSP (JavaServer Pages), HTML5, CSS3, JavaScript
* **Database:** MySQL
* **Server:** Apache Tomcat v10.1
* **Version Control:** Git & GitHub (Managed via Eclipse IDE)
